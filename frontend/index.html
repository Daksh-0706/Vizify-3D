Hands-free controls

  • Thumbs-up = clutch on/off (nothing moves unless ON)
  • Pinch + move (1 hand) = rotate
  • Pinch both hands, spread/close = zoom
  • Open palm + move = pan
  • Fist = reset view
  • Point = hover/select part (featured)
  • Mouse + OrbitControls always works for debugging.

Tip: good light, hand 40–70cm from webcam, slow moves.
